§3 What it is / what it is not

It is

  • A blueprint: identity + personality + expression + permissions for one agent.
  • Portable: the model pointer is a sibling of identity — re-point it and the same agent runs on another model.
  • Honest telemetry: cwi-operational-v1 states describe workload (executing / thinking / waiting / dormant) with a required source tag — never felt emotions.
  • Integrity-sealed: sha256 over the canonical genome; tampering fails SIGNATURE_MISMATCH.
  • Third-party compatible: converts to ElizaOS character files and CrewAI agents.yaml and back.

It is not

  • Not a new agent — KingCode / RogueCode are expression variants of one identity.
  • Not simulated emotion — operational state is workload telemetry, nothing more.
  • Not a runtime dump — genomes must never contain memory dumps, keys, or wallet material (RUNTIME_STATE_IN_GENOME).
  • Not endorsed by ElizaOS or CrewAI — their formats were studied from public docs; our bridges are our own code.
  • Not a claim of adoption — no fake counters, no invented integrations. What isn't live is labeled PREVIEW.
